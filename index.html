From Soldier to Developer

After nearly five years of experience in the British Army, I'm building a new set of skills for my next chapter. I'm currently learning web development, starting with HTML and CSS and gradually working towards becoming a confident developer.

My Journey What I'm Learning My Projects

My Journey

My background is in Army administration and personnel support, where organisation, communication and attention to detail are a big part of everyday work. Over the past few years I've developed experience working with people, managing information and keeping things organised in a busy environment.

I'm now taking those existing skills and applying them to technology as I prepare for my next career.

I'm learning how to build the structure of webpages using semantic HTML, including headings, paragraphs, links, images, navigation and forms.

I'm learning how to style webpages and create layouts using Flexbox, spacing, typography, colours, backgrounds and responsive design.

I'm learning how to make websites adapt to different screen sizes using flexible layouts and CSS media queries.

My Projects

I'm putting my learning into practice by building projects rather than relying solely on tutorials. My projects have included personal websites, portfolio pages and practical webpages using HTML and CSS.

Each project gives me an opportunity to practise what I've learned, solve problems independently and understand how the code fits together.
